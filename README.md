# Modern Calculator

A clean, responsive web calculator with basic arithmetic operations, keyboard support, and a polished modern user interface.

Built with plain HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers and percentage calculations
- Positive/negative toggle, clear, and backspace
- Keyboard support
- Graceful division-by-zero handling
- Responsive dark theme for desktop and mobile
- No frameworks, dependencies, or `eval()`

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Keyboard shortcuts

Use `0-9`, `.`, `+`, `-`, `*`, `/`, `%`, `Enter` or `=`, `Escape`, and `Backspace`.
